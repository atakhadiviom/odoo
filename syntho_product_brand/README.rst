Syntho Product Brand
====================

**Version:** 19.0.1.0.0 | **License:** LGPL-3 | **Author:** SynthoERP

Add a Brand field to your products and organise your catalog by brand.

Features
--------

- Dedicated Brand model with name and description
- Brand field on Product Templates
- Filter and group products by brand in list views
- Role-based access: all internal users read; admins manage

Installation
------------

1. Copy ``syntho_product_brand`` to your addons path
2. Restart Odoo and update the app list
3. Install **Syntho Product Brand**
4. Go to **Sales → Configuration → Product Brands** to create brands, then
   assign them on product forms

Dependencies
------------

- ``product``
- ``sale``
