Thawani Payment

Accept Thawani Pay checkout payments from Odoo eCommerce and confirm transactions only after the checkout session is verified.

Hosted checkout

Redirect customers to Thawani Pay for card payment.

Verified return

Checks the Thawani session before Odoo confirms payment.

Key Features

Payment provider setup

Adds Thawani as an Odoo payment provider with secure credential fields.

OMR checkout session

Creates Thawani checkout sessions with order reference and total amount.

Odoo status update

Maps verified Thawani payment statuses to Odoo transaction states.

External Service Notice

This module sends checkout data to Thawani Pay, including the transaction reference, order total, customer name, and sale order reference when available. A valid Thawani merchant account, secret key, and publishable key are required.
