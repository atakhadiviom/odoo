Inventory Configuration

Barcode Nomenclature Enable

Bring the hidden Barcode Nomenclatures menu back to Odoo 19 Community so Inventory Managers can maintain barcode parsing rules without developer mode or technical workarounds.

Odoo 19 Inventory Community Edition XML Only

Why It Matters

A small module that unlocks an important Inventory configuration screen.

Visible Menu Entry

Exposes the Barcode Nomenclatures menu under Inventory configuration where users expect it.

Rule Maintenance

Inventory Managers can create, edit, and remove nomenclatures and their rules directly.

Weight and Price Codes

Useful for scale barcodes, price-embedded barcodes, and custom internal rule sets.

GS1 Compatible

Works alongside the built-in GS1 nomenclature module already available in Odoo.

Typical Use Cases

  • Define scale barcode prefixes for weighted products.
  • Maintain price-embedded barcode rules for retail operations.
  • Let functional inventory users manage barcode logic without technical menus.

Lightweight Footprint

The addon only exposes the missing menu entry. It does not add Python code, database schema changes, or extra configuration models.

Installation

Step 1

Copy barcode_nomenclature_enable into your addons path.

Step 2

Restart Odoo and update the Apps list.

Step 3

Install Barcode Nomenclature Enable.

Step 4

Open Inventory > Configuration > Products > Barcode Nomenclatures.
