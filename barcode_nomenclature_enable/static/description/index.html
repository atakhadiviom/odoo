Inventory Configuration

Barcode Nomenclature Enable

Unlock the hidden Barcode Nomenclatures menu in Odoo 19 Community and give Inventory Managers access to the barcode rules they actually need to manage day-to-day operations.

Odoo 19 Community Inventory No Python Logic

Why This Add-on Exists

In standard Odoo 19 Community, the Barcode Nomenclatures menu is hidden from normal business users. That makes it unnecessarily hard to review, tune, or maintain barcode rules for warehouse scanners, POS labels, or weighing-scale formats. This module restores the menu to Inventory Managers without changing the underlying barcode engine.

What changes:
  • The Barcode Nomenclatures menu becomes visible under Inventory configuration.
  • Managers can maintain nomenclatures and their rules through the standard UI.
  • Existing Odoo barcode behavior remains untouched.

What You Get

Menu Access Restored

Makes the standard Barcode Nomenclatures screen available to the stock manager role directly from Inventory settings.

Rule Maintenance in the UI

Create, edit, review, and remove nomenclature rules without relying on developer mode or technical menus.

Compatible With Real Barcode Flows

Useful for weight barcodes, price barcodes, and custom prefix setups commonly used in retail, warehousing, and POS environments.

Safe and Focused

This is a small visibility override only. It does not replace Odoo's barcode parsing models or alter existing barcode logic.

Installation

1
Place the module in your custom addons path Copy barcode_nomenclature_enable into the addons directory used by your Odoo server.
2
Update the app list Refresh the Apps list from Odoo so the module becomes available for installation.
3
Install the add-on Search for Barcode Nomenclature Enable and install it like any other Odoo app.
4
Open the restored menu Go to Inventory -> Configuration -> Products -> Barcode Nomenclatures.
Dependencies barcodes, stock
Best For Teams using barcode scanning, POS labels, weighted products, or custom barcode prefixes
Technical Scope Menu visibility only, using standard Odoo views and security groups
