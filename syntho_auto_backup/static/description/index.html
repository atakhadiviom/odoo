Database Safety

Syntho Auto Backup

Create scheduled Odoo database backups with a simple admin screen, timestamped files, and a controlled backup directory structure that fits cleanly into Odoo 19 operations.

Odoo 19 Administration Zip or Dump Scheduled Cron

What This Module Does

The module introduces a backup configuration model where administrators can define a backup name, destination folder, and output format. An Odoo scheduled action runs the backup process and generates timestamped files using either Odoo's zip dump or PostgreSQL custom dump format.

Scheduled Execution

The module includes an Odoo cron job ready to run database backups automatically.

Two Output Formats

Choose between zip backups through Odoo or custom dump backups through pg_dump.

Multiple Backup Configurations

Create more than one backup rule when you need different folders or output formats.

Controlled File Paths

Backup folders are validated against the configured base backup directory for safer storage handling.

Operational note:
  • the Odoo service user must be able to write to the configured backup folder
  • dump format relies on PostgreSQL dump tooling on the server
  • backup folders must stay within the configured base backup directory

Installation

1
Copy the module into your addons path Place syntho_auto_backup in the custom addons directory used by your server.
2
Update the Apps list Refresh Odoo's app registry so the backup module appears in Apps.
3
Install Syntho Auto Backup Install the module from Apps and open the Auto Backup menu.
4
Create your backup configuration Define the folder and format, then enable or schedule the cron according to your policy.
Dependency base
Configuration Fields Name, backup directory, and backup format
Output Naming Database name plus timestamped file naming for easier backup tracking
