Database Safety

Syntho Auto Backup

Schedule Odoo database backups from a simple administration screen, choose the output format you need, and keep backup folders inside a controlled base directory.

Odoo 19 Administration Zip or Dump Scheduled Cron

What You Get

A small Odoo 19 utility focused on repeatable, server-side database backups.

Scheduled Execution

The module ships with an Odoo scheduled action that processes all configured backup rules automatically.

Two Output Formats

Generate either a zip backup through Odoo or a PostgreSQL custom dump through pg_dump.

Multiple Configurations

Create more than one backup rule when different folders or formats are needed for the same database.

Safer Paths

Backup directories are validated against a configured base path to reduce accidental writes outside the intended storage area.

How It Works

Administrators create backup configurations with a name, a folder, and a format. The scheduled action loops through those records, creates timestamped filenames, and writes the backup file on the server.

  • Each backup file includes the database name and a timestamp.
  • Zip format uses Odoo's own database dump routine.
  • Dump format uses PostgreSQL tools available on the host machine.

Operational Notes

  • The Odoo service user must be able to write to the selected folder.
  • pg_dump must be available on the server for dump format.
  • Configured folders must stay within the base backup directory.

Installation

Step 1

Copy syntho_auto_backup into your custom addons path.

Step 2

Restart Odoo and update the Apps list.

Step 3

Install Syntho Auto Backup from Apps.

Step 4

Open Auto Backup, create your configurations, and schedule the cron as needed.
