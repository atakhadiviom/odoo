Syntho Auto Backup

Odoo 19 Community Free Administration

Automatically back up your Odoo database on a configurable schedule. Never lose critical business data due to a missed manual backup.

Features

Scheduled Backups

Configure automated backups via an Odoo cron job at any frequency — hourly, daily, weekly.

Local Storage

Backups are saved to a configurable local directory path on the server.

Multiple Formats

Choose between zip (includes filestore) or dump (SQL only) backup formats.

Retention Policy

Automatically remove old backups to keep disk usage under control.

Manual Trigger

Run a backup on demand at any time from the configuration screen.

Admin UI

Simple settings form accessible under Settings — no server SSH access needed.

How to Install

1
Copy the syntho_auto_backup folder to your custom addons path.
2
Add the path to addons_path in your odoo.conf.
3
Go to Settings → Apps, click Update App List, search for Syntho Auto Backup and install.
4
Configure your backup schedule and storage path under the Auto Backup configuration.
Note: Ensure the Odoo server process has write permission to the backup destination directory.
