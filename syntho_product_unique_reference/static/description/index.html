Catalog Integrity

Syntho Unique Product Reference

Keep internal references clean and dependable by blocking duplicate SKUs anywhere in the product catalog while still allowing blank references when your workflow requires them.

Odoo 19 Product Data Quality Validation Constraint

What It Protects

Duplicate internal references can break warehouse processes, barcode expectations, purchasing logic, and reporting. This module adds a validation rule on products so Odoo raises a clear error before a duplicate SKU enters the database.

Duplicate Prevention

Stops users from saving a product when the same internal reference already exists elsewhere.

Batch Creation Coverage

Checks duplicates created in the same batch as well as duplicates already present in the database.

Blank Values Still Allowed

Only filled references must be unique; empty or unset values continue to work normally.

Pure Business Logic

No menus, no XML configuration, and no additional models - just a focused Python constraint.

Especially useful when:
  • multiple users create products or variants in parallel
  • catalogs are imported from spreadsheets or external systems
  • SKUs are treated as a strict operational key in inventory and sales

Installation

1
Copy the module to your addons path Place syntho_product_unique_reference in the custom addons directory used by your Odoo server.
2
Refresh the Apps list Update the module registry so Odoo detects the add-on.
3
Install the module Install Syntho Unique Prod Ref from the Apps menu.
4
Work as usual From that point on, duplicate internal references are blocked automatically during save or batch create.
